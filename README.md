# Environment Variables Management

## Installation

```bash
go get github.com/nlgolib/env
```

## Functionality Highlights

- [x] Register environment variables
- [x] Record environment variables to a map
- [x] Get environment variables as string
- [x] Get environment variables as boolean
- [x] Get environment variables as integer
- [x] Get environment variables as float64
- [x] Get environment variables as JSON
- [x] Get environment variables as slice of strings
- [x] Get environment variables as slice of integers
- [x] Get environment variables as slice of float64
